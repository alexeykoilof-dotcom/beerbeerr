# Roulette Wheel and Board

- Исходная модель: `roulettewheel2.obj`
- Автор: Klooverice
- Источник: https://opengameart.org/content/roulette-wheel-and-board
- Лицензия: Creative Commons Zero (CC0)
- Страница лицензии: https://creativecommons.org/publicdomain/zero/1.0/

Исходный ассет содержит геометрию колеса и игрового поля без текстур. Материалы,
основание стола, отдельные цветные ячейки, шарик, кнопки ставок и игровая логика
добавлены в Godot в `res://roulette_table.tscn`. Все эти элементы редактируемые.
